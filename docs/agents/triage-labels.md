# Triage Labels

스킬들은 다섯 가지 표준 트리아지 역할로 이야기합니다. 이 파일은 그 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 매핑합니다. 로컬 마크다운 트래커이므로 라벨은 각 이슈 파일의 `Status:` 줄에 기록합니다.

| mattpocock/skills 라벨 | 우리 트래커 라벨  | 의미                                   |
| ---------------------- | ----------------- | -------------------------------------- |
| `needs-triage`         | `needs-triage`    | 관리자가 이 이슈를 평가해야 함         |
| `needs-info`           | `needs-info`      | 작성자의 추가 정보를 기다리는 중       |
| `ready-for-agent`      | `ready-for-agent` | 명세가 완성되어 AFK 에이전트가 처리 가능 |
| `ready-for-human`      | `ready-for-human` | 사람이 직접 구현해야 함                |
| `wontfix`              | `wontfix`         | 처리하지 않음                          |

스킬이 역할을 언급하면 (예: "apply the AFK-ready triage label") 이 표에서 해당하는 라벨 문자열을 사용합니다.

실제로 쓰는 용어에 맞추려면 "우리 트래커 라벨" 열을 수정하세요.
